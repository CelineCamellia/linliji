# 本机启动

需要 Node.js 24.18 或更高的 24.x 版本，以及 npm。无需先申请微信账号或安装数据库。

```sh
npm ci
npm run quickstart
```

第一次会编译网页，并在 `.local/runtime.env` 写入随机管理员密码。后续启动复用配置和数据库，不覆盖已有资料。

| 入口                         | 用途                                                |
| ---------------------------- | --------------------------------------------------- |
| http://127.0.0.1:8788        | 居民页面，先注册一个账号                            |
| http://127.0.0.1:8788/admin/ | 管理页面，账号 `admin`，密码见 `.local/runtime.env` |

建议按以下顺序走一遍：

1. 注册居民账号，发布一条闲置、手艺或交换信息。照片选填，手机号仅登录联系时提供。
2. 新开浏览器窗口进入管理页面，查看文字与照片，填写理由后通过审核。
3. 回到居民页面查看公开信息。修改发布后会重新等待审核。
4. 注册第二个居民账号，查看联系方式并提交举报，再从管理页面处理。
5. 切换城市、选择社区，检查列表。洛阳及石油社区、地矿社区只是初始例子，也能输入其他名称。

本机启动使用真实注册、密码验证和人工审核，不预置商家或居民数据。浏览无需账号。

## 日常开发

修改网页后运行 `npm run build`，刷新页面。`quickstart` 仅在构建文件不存在时自动编译；服务端代码改变后需要重启。

`npm run dev` 启动历史演示模式和 Vite 热更新，默认使用 `server/data`，包含明确标记的示例商品及订单流程。它与 `.local` 的真实账号流程分开，不用于对外部署。

## 文件和端口

`.local/linliji.sqlite` 是本机数据库，`.local/uploads` 是照片。退出终端停止服务，数据仍保留。需要独立空环境时，使用新的项目目录；不要直接删掉已有数据库。

端口冲突时，先检查是否已经运行过项目。需要换端口，可把 `.local/runtime.env` 的 `PUBLIC_ORIGIN` 改为 `http://127.0.0.1:8790`。此启动入口只监听回环地址，手机不能通过电脑的公网地址访问它。

管理员密码不会写进网页或构建产物。公开提交时应保留 `.gitignore`，不要提交 `.local`、`runtime.env`、数据库、上传照片和签名文件。
